# Issues de Saneamiento para Entrega del TFG

Este documento resume los issues creados en GitHub para cerrar la entrega del TFG con un alcance realista y defendible.

## Objetivo

Priorizar seguridad, consistencia funcional, trazabilidad tecnica y alineacion entre memoria y codigo real.

## Bloques de trabajo

1. Seguridad y control de acceso
2. Reglas de negocio del kanban y tareas
3. Consistencia de dominio y datos
4. Base de datos y despliegue
5. Tests y validacion
6. Arquitectura y limpieza tecnica
7. Memoria, README y defensa

## Criterio general

Cada issue debe cerrarse solo cuando:

- exista cambio verificable en codigo o documentacion,
- quede trazado en commit o PR,
- y el resultado sea defendible en memoria y demo.

## Nota

La prioridad de ejecucion recomendada es:

1. Proteger API y registro
2. Subir reglas criticas al backend
3. Corregir bug de facturas
4. Formalizar esquema con migraciones
5. Reforzar tests
6. Alinear memoria con estado real
