## Uso de estos documentos en el TFG

Estos documentos permiten justificar:

- el problema abordado por la aplicacion,
- la arquitectura elegida y su estado real,
- la estructura del dominio y la base de datos,
- la correspondencia entre requisitos y funcionalidades implementadas,
- las decisiones tecnicas tomadas durante el desarrollo,
- y las limitaciones o lineas futuras sin necesidad de inflar el alcance con mas codigo.
