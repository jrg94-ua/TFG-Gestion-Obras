## Uso recomendado

Estos documentos no sustituyen al formato final exigido por la universidad, pero permiten:

- consolidar el contenido tecnico ya trabajado,
- mantener coherencia entre codigo y memoria,
- y acelerar la redaccion final sin improvisar en la fase de cierre.

## Orden sugerido para la memoria

Una estructura razonable para la redaccion final seria:

1. objetivos, alcance y metodologia,
2. arquitectura y decisiones tecnologicas,
3. modelo de datos y reglas de negocio,
4. requisitos y trazabilidad,
5. desarrollo de modulos funcionales,
6. pruebas, limitaciones y lineas futuras.
